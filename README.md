# Diagram-Ishikawy
Diagram Ishikawy to graficzne narzędzie analizy przyczynowo‑skutkowej, które porządkuje możliwe źródła problemu w kategoriach 5M/6M. Ułatwia zespołom identyfikację przyczyn, oddzielanie faktów od hipotez i planowanie działań naprawczych w produkcji, usługach i procesach biznesowych.
Czym jest diagram Ishikawy
Diagram Ishikawy to wizualne narzędzie jakości, które przedstawia związek między skutkiem (problemem) a możliwymi przyczynami, uporządkowanymi w kategorie takie jak ludzie, metoda, materiał, maszyna, pomiar, środowisko (model 5M/6M)
